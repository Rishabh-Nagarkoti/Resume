Woman Safety Application and Website

A dual-platform safety solution designed to help women in emergency situations. The system includes both a mobile application and a web platform, offering real-time SOS alerts, location tracking, and access to emergency contacts.

Key Features:

  • One-touch SOS alert with location sharing to emergency contacts
  • Shake-to-alert emergency trigger
  • Live location tracking for trusted contacts
  • Nearby safe zones and police stations displayed using Google Maps
  • Anonymous incident reporting via web platform
  • Admin dashboard with real-time incident data and user management

Technologies Used:

  • Frontend: HTML, CSS, JavaScript, React (for web), Android/Kotlin (for app)
  • Database: Google Firebase
  • APIs: Google Maps API, Twilio/Firebase for messaging
